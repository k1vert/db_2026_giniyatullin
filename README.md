Название проекта: Информационная система автосервиса «AutoFix»

Краткое описание предметной области:
    Проект представляет собой базу данных для автоматизации работы автосервиса. Система позволяет регистрировать клиентов и их автомобили, назначать мастеров на выполнение конкретных ремонтных работ, а также вести строгий учет использованных в процессе ремонта автозапчастей и их стоимости.

Платформа решает проблему хаотичного контроля за выполнением заказов, помогает отслеживать историю ремонта каждой машины и автоматизирует расчет итоговой стоимости наряд-заказа для клиента.
